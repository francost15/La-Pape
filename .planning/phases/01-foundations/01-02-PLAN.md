<task type="auto">
  <name>Task 1: Install jest-expo and create jest.config.js</name>
  <files>jest.config.js, package.json</files>
  <action>
    1. Install jest-expo:
       ```
       npx expo install jest-expo
       ```
       This installs jest-expo and its peer deps (jest, babel-jest, @jest/globals). Do NOT pin a version — use npx expo install to get the SDK-compatible version.

    2. Create jest.config.js at the project root:
       ```js
       module.exports = {
         preset: "jest-expo",
         testMatch: ["**/src/test/**/*.test.[jt]s?(x)"],
         setupFilesAfterFramework: ["<rootDir>/src/test/setup.ts"],
         moduleNameMapper: {
           "^@/(.*)$": "<rootDir>/$1",
         },
         transformIgnorePatterns: [
           "node_modules/(?!((jest-)?react-native|@react-native(-community)?)|expo(nent)?|@expo(nent)?/.*|@expo-google-fonts/.*|react-navigation|@react-navigation/.*|@unimodules/.*|unimodules|sentry-expo|native-base|react-native-svg|nativewind|zustand|@shopify/flash-list)",
         ],
       };
       ```

       NOTE: The correct key is `setupFilesAfterFramework` for jest-expo (maps to Jest's setupFilesAfterFramework). If jest-expo uses `setupFilesAfterFramework` vs `setupFilesAfterFramework` — double-check the jest-expo README at install time. Use whichever the installed version expects.

    3. Update package.json scripts:
       - Change `"test": "vitest run"` → `"test": "jest"`
       - Change `"test:watch": "vitest"` → `"test:watch": "jest --watch"`
       - Change `"test:coverage": "vitest run --coverage"` → `"test:coverage": "jest --coverage"`
       - Remove `"test:ui": "vitest --ui"` — no jest equivalent needed
       - Keep e2e scripts unchanged

    4. Remove vitest and its plugins from devDependencies in package.json:
       - Remove: `vitest`, `@vitejs/plugin-react`, `@vitest/coverage-v8`
       - Keep: `@testing-library/react-native`, `@testing-library/jest-native`, `@types/jest`, `react-test-renderer`
       - Run `npm install` after editing package.json to update the lockfile

    5. If vitest.config.ts exists at the root, delete it — it is superseded by jest.config.js.

  </action>
  <verify>
    <automated>node -e "require('./jest.config.js'); console.log('jest.config.js valid')"</automated>
  </verify>
  <done>
    jest.config.js exists with jest-expo preset and correct transformIgnorePatterns. package.json test script runs jest. vitest removed from devDependencies.
  </done>
