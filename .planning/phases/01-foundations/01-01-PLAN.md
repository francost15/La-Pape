<task type="auto">
  <name>Task 3: Rewrite firestore.rules with multi-tenant isolation</name>
  <files>firestore.rules</files>
  <action>
    Replace the entire content of firestore.rules with a hardened multi-tenant ruleset.

    Key design:
    - Helper function `isMember(negocioId)`: checks `exists(/databases/$(database)/documents/usuarios_negocios/$(request.auth.uid + '_' + negocioId))`
    - Helper function `isAdmin(negocioId)`: calls isMember AND gets the document to check `rol == 'ADMIN'`
    - All collections with negocio_id isolation: `productos`, `categorias`, `ventas`, `ventas_detalle`, `ventas_pagos`, `inventario_movimientos`
    - `usuarios/{userId}`: only the owner can read/write their own document
    - `usuarios_negocios/{membershipId}`: only the member can read their own doc; only admin of that negocio can create/update
    - Default catch-all: `match /{document=**} { allow read, write: if false; }`

    Full rules structure:
    ```
    rules_version = '2';

    service cloud.firestore {
      match /databases/{database}/documents {

        function isAuthenticated() {
          return request.auth != null;
        }

        function memberDocPath(negocioId) {
          return /databases/$(database)/documents/usuarios_negocios/$(request.auth.uid + '_' + negocioId);
        }

        function isMember(negocioId) {
          return isAuthenticated() && exists(memberDocPath(negocioId));
        }

        function isAdmin(negocioId) {
          return isMember(negocioId) &&
            get(memberDocPath(negocioId)).data.rol == 'ADMIN';
        }

        match /usuarios/{userId} {
          allow read, write: if isAuthenticated() && request.auth.uid == userId;
        }

        match /usuarios_negocios/{membershipId} {
          allow read: if isAuthenticated() &&
            (membershipId == request.auth.uid + '_' + resource.data.negocio_id);
          allow create: if isAuthenticated() &&
            request.auth.uid == request.resource.data.usuario_id &&
            membershipId == request.resource.data.usuario_id + '_' + request.resource.data.negocio_id;
          allow update: if isAdmin(resource.data.negocio_id);
        }

        match /productos/{productId} {
          allow read: if isMember(resource.data.negocio_id);
          allow create: if isAdmin(request.resource.data.negocio_id) &&
            request.resource.data.negocio_id is string &&
            request.resource.data.precio_venta is number &&
            request.resource.data.cantidad is number;
          allow update: if isAdmin(resource.data.negocio_id);
          allow delete: if isAdmin(resource.data.negocio_id);
        }

        match /categorias/{categoriaId} {
          allow read: if isMember(resource.data.negocio_id);
          allow create: if isAdmin(request.resource.data.negocio_id);
          allow update, delete: if isAdmin(resource.data.negocio_id);
        }

        match /ventas/{ventaId} {
          allow read: if isMember(resource.data.negocio_id);
          allow create: if isMember(request.resource.data.negocio_id) &&
            request.resource.data.total >= 0;
          allow update: if isMember(resource.data.negocio_id);
        }

        match /ventas_detalle/{detalleId} {
          allow read: if isMember(resource.data.negocio_id);
          allow create: if isMember(request.resource.data.negocio_id) &&
            request.resource.data.cantidad > 0 &&
            request.resource.data.precio_unitario >= 0;
        }

        match /ventas_pagos/{pagoId} {
          allow read: if isMember(resource.data.negocio_id);
          allow create: if isMember(request.resource.data.negocio_id);
        }

        match /inventario_movimientos/{movId} {
          allow read: if isMember(resource.data.negocio_id);
          allow create: if isMember(request.resource.data.negocio_id);
        }

        match /{document=**} {
          allow read, write: if false;
        }
      }
    }
    ```

    NOTE: ventas, ventas_detalle, ventas_pagos, and inventario_movimientos documents must include a `negocio_id` field. Verify the existing write services set this field — if any service omits negocio_id, the Firestore write will be rejected by these rules and the calling service must be updated.

    Deploy rules after writing: `firebase deploy --only firestore:rules` (requires firebase CLI). If not available in the environment, leave a comment noting manual deploy is needed.
